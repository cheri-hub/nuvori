# Final Fix Report: Nuvori Home Visual Prototype

## Status

All eight final-review findings are addressed in the local-only React prototype. No backend, authentication provider, persistence, or networking was added.

## Changes

1. Normal completion and reward gating
   - `END_NORMAL` now requires an `endedAt` timestamp and uses the existing deterministic timestamp clock to verify completion inside the reducer.
   - The host's normal `Encerrar` control remains disabled until the displayed clock is complete.
   - Adapted and interrupted actions remain explicit early exits.

2. Persistent Muru stage and per-session line
   - Added persistent `muruStage` state separately from `lineProgress`.
   - Session starts and returns to Home reset `lineProgress` to `0`; capsule display uses `1` only for the completed session.
   - Returning Home and starting a subsequent session preserve `muruStage`.

3. Recommendation continuity
   - Home prompt and CTA derive their text from `state.durationMinutes`.
   - A selected 10-minute recommendation remains `Comecar 10 min` after a valid adapted session returns Home.

4. Keyboard-accessible sheets
   - Added shared `useModalDialog` behavior for both sheets.
   - Focus moves to the close button, Tab and Shift+Tab wrap inside the dialog, Escape closes, and focus returns to the originating Home action.
   - Header and bottom navigation receive both `aria-hidden="true"` and `inert` while a sheet is open, with their previous state restored on close.

5. Local social invite host flow
   - `JOIN_INVITE` now simulates an authenticated participant joining the host's pending invite instead of changing the local user into a participant.
   - The invite sheet renders Lia Alves with a public initials avatar and authenticated-profile status before offering a separate social-session start action.
   - `START_SOCIAL` preserves `isHost: true`, and active host controls appear only after the host starts.

6. Muru walking and reward moods
   - Muru exposes distinct mood modifier classes and uses the existing local SVG asset.
   - Walking uses a light step animation and amber line; reward uses a restrained reveal treatment and coral line.
   - Reduced-motion CSS disables displacement while preserving color/state differences.
   - Capsule reveal now renders the reward mood.

7. Document language
   - `index.html` now declares `lang="pt-BR"`.

8. Reducer authorization
   - `isHost` is enforced for pause, resume, normal end, adapted end, and interrupted end reducer actions.
   - Participant attempts return the same state object.
